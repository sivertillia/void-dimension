# The Void Dimension

Мод для **Minecraft 1.21.1** (NeoForge 21.1.234), який дає кожному гравцю **власний
приватний вимір «Порожнечі»** — темний порожній кишеньковий світ для будівництва, з системою
доступу, щоб пускати туди інших.

> Автор: FinnK42 · Версія: 1.0.0 · Ліцензія: MIT

## Можливості

- **Окремий вимір на кожного гравця.** Кожен гравець отримує власний вимір
  (`void_dimension:<uuid>`), який створюється на вимогу при першому вході й зберігається в окремих
  region-файлах. Ніхто не ділить світ — будівлі не перетинаються. Виміри створюються динамічно в
  рантаймі (публічного API для цього в Minecraft немає, тож мод містить невеликий access-transformer).
- **Void Teleporter (телепортер).** Затисни предмет (анімація як у лука, партикли порожнечі), щоб
  переміститися:
  - **Без назви** → у твій власний воід, а зсередини — назад (запам'ятовує, звідки ти прийшов).
  - **Перейменований на нік гравця** (напр. в анкові) → у воід **того** гравця, якщо він існує і
    тобі туди можна (власник, виданий доступ, або ти OP). Інакше побачиш причину відмови.
- **Система доступу.** Дозволяй і забирай, хто може заходити у твій воід; адміни (OP) ігнорують ці правила.
- **Void Monolith (моноліт).** Міцний блок, що світиться й форс-лоадить свій чанк, поки стоїть у воіді.
- **Конфіг** (`Config.java`) — яскравість і міцність моноліту, світіння телепортера.

## Команди

Усі під `/void`:

| Команда | Хто | Дія |
|---------|-----|-----|
| `/void access <нік>` | усі | дозволити гравцю заходити у **твій** воід |
| `/void revoke <нік>` | усі | забрати доступ |
| `/void my list`      | усі | показати, кому ти відкрив доступ до свого воіда |
| `/void tp <нік>`     | OP  | телепортуватися в будь-який наявний воід |
| `/void list`         | OP  | список усіх наявних воідів |

Ніки резолвляться через кеш профілів сервера, тож команди й перейменований телепортер працюють і
для офлайн-гравців. Команди **ніколи не створюють** новий воід — це робить лише власний телепортер власника.

## Структура проєкту

| Шлях | Вміст |
|------|-------|
| `src/main/java/com/finnk42/void_dimension/` | Код мода (головний клас, конфіг, блок, предмет, `command/`, `world/`, `init/`) |
| `.../world/VoidDimensions.java` | Створення персональних вимірів у рантаймі |
| `.../world/VoidAccess.java` | Персистентні списки доступу (`SavedData`) |
| `.../command/VoidCommand.java` | Дерево команд `/void` |
| `src/main/resources/META-INF/accesstransformer.cfg` | Відкриває внутрішні поля сервера для динамічних вимірів |
| `src/main/resources/data/void_dimension/` | Шаблонний вимір, біом, рецепти, ачівки |
| `src/main/resources/assets/void_dimension/` | Моделі, текстури, blockstates, локалізація |

## Збірка

Потрібен **JDK 21**. Gradle сам підтягне NeoForge та Minecraft.

```bash
./gradlew build        # jar з'явиться в build/libs/
./gradlew runClient    # запуск гри для тестів
```

На Windows — `gradlew.bat` замість `./gradlew`. CI збирає проєкт на кожен push/PR через
`.github/workflows/build.yml`.

## Нюанси та обмеження

- Динамічні виміри відтворюються на вимогу, а не при старті сервера. Region-файли зберігаються, тож
  будівлі переживають рестарт; воід гравця відтворюється при наступному вході (його або його
  телепортера). Якщо гравець вийшов, стоячи всередині свого воіда, після рестарту його перекине на
  спавн Overworld, доки він не зайде знову.
